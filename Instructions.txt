ENABLING HTTPS
1. go to C:\xampp\apache\conf
2. create a new folder with name "ssl", inside copy and paste the files available inside the folder "cert" in the GitHub folder
3. open xampp control panel, in the apache row click on config and select httpd-ssl.conf
4. locate the lines :
	SSLCertificateFile and insert the path "C:/xampp/apache/conf/ssl/server.crt"
	SSLCertificateKeyFile and insert the path "C:/xampp/apache/conf/ssl/server.key"
5. restart the apache server
6. go to the browser and type https://127.0.0.1, it will show not secure connection, proceed anyway, the server will now successfully use ssl
7.(optional) if you want to remove the warning, go in the folder of the file server.crt , rigth click on it, select install certificate, then manually choose the location
, select root certificate, finish. Restart apache and the browser, go to the platform page.

CLEANING OLD SESSION DATA
Since the introduction of timestamp, the session id is periodically regenerated every time an user is idle for more 
than 15 minutes with (false) argument (i.e. the session id is changed but old session will be kept). 
This prevent problems related to slow internet connection or latency. The increased number of old session
must be hadled to avoid momery risks. Normally php do that with the settings present in the .ini file. We will just increase
the number of checks for this sessions since it works with a probability.
Go in ../xampp/php/php.ini and change those settings:
session.gc_probability = 1
session.gc_divisor = 1         ; 100% chance - runs every time
session.gc_maxlifetime = 900
Then relaunch the server

To hide php file listing:
Goto Apache (httpd.conf) and locate:
Options Indexes FollowSymLinks Includes ExecCGI 
(inside Directory tag of DocumentRoot) 
replace with: Options FollowSymLinks
It simply forbidden the access of /php content directly. (Indexes)
Prevent CGI (execution of scripts)
Prevent old type of inclusion of files (Includes)
-----------------------------------------------------------
To Hide Apache Details:
Goto xampp\apache\conf\extra\httpd-default.conf
locate:
ServerTokens Full
ServerSignature On
Change to:
ServerTokens Prod
ServerSignature Off

Hide PHP details

Disable showing errors
